  <files>tools/am_evidence/am_evidence_map.py</files>
  <action>
Add, without changing existing subcommands' behavior:
- Constants: `VERDICTS_MD`, `VERDICTS_DIR` (phase 191 folder), `VALID_VERDICTS`,
  `VALID_VERDICT_EVIDENCE`, `VALID_CHECK_STATUS = {"COMPLETE","PARTIAL","SKIPPED","FAILED","—"}`.
- `_parse_verdicts()`: frontmatter (`query_workbook`), Verdict Table (9 columns, using the existing
  markdown table parser), Lead Summary (`### L1`…`### L9` and `### Other items`, each with Overall /
  Rests on / Complete).
- `cmd_verdicts_export(args)`:
  1. `--date`: default today `%Y%m%d`; reject anything not `^\d{8}$` that is not a valid calendar date.
  2. Parse map and verdicts. Required set = live map rows with Status FILLED-NEEDS-CHECK or BLOCKED.
  3. Collect all failures, then exit 1 listing them:
     - required IDs without a verdict; duplicate verdict IDs; verdict IDs not in the required set
     - verdict Lead ≠ map Lead
     - invalid Verdict / Evidence Type / Check Status values
     - MATCH with Check Status not in {COMPLETE, —}; MATCH whose evidence types are only PLANNING-DOC
     - MISMATCH/PARTIAL without `^D-191-\d{2}$`; non-MISMATCH/PARTIAL rows with a D-191-NN
     - D-191-NN missing from AM-MAP-03 or the ID Registry; its Map Row(s) ≠ the verdict's Map ID
     - D-191-NN rows in AM-MAP-03 with no verdict row
     - Lead Summary missing any of L1–L9 or missing a `Complete:` value of `yes` / `no — …`
     - count lint: in What the Code Does / What the Manual Says Differently / Lead Summary text,
       any `\b([1-9]|10)\b` immediately followed or preceded (within 3 words) by
       patients|encounters|rows|records|people|n= → failure with the location
  4. Gaps = verdict rows with BLOCKED or CANNOT-VERIFY, plus one row per lead whose Complete is `no`
     (reason = the text after `no —`).
  5. Write `am_verdicts_<date>.xlsx` to `VERDICTS_DIR` with the existing styling helpers:
     - KEY: title, generated date, query workbook name, sources (both markdown paths), verdict and
       evidence definitions, decision-status meaning (OPEN = team question; CONFIRMED = manual
       update only), "No patient-level data", sheet guide.
     - Verdicts: all 9 columns; MISMATCH/PARTIAL rows with #FA4616 fill on the Verdict cell;
       BLOCKED/CANNOT-VERIFY with light grey.
     - Lead Summary: Lead | Overall | Rests on | Complete (L1–L9, then Other items).
     - Decisions: D-191-NN rows from AM-MAP-03 with all their columns.
     - Gaps: Map ID or Lead | Lead | Verdict/Complete | Reason.
     Header fill #0021A5, white bold; freeze top row; wrap long text.
  6. Reopen the workbook and compare with the parsed markdown: sheet order, row counts, Map IDs,
     verdicts, decision IDs. Any difference → exit 1.
  7. Print the output path and counts (verdicts by value, D-191 OPEN/CONFIRMED, gaps).
- Update the module docstring and argparse dispatch.
