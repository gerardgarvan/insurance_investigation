**New function `_parse_verdicts(verdicts_path)`:**
Parse AM-VERDICTS.md markdown table into a list of dicts. The table header is:
`| Map ID | Lead | Verdict | Evidence Type(s) | Citation(s) | What the Code Does | What the Manual Says Differently | Decision ID |`

Return:
```python
{
  "verdict_rows": list of dicts with keys: map_id, lead, verdict, evidence_types, citations, code_description, manual_difference, decision_id
  "lead_summary": dict keyed by lead (L1..L9, c0) with value = text block
}
```

Strip leading/trailing whitespace from all values. Parse the `## Lead Summary` section by extracting `### L{N}` blocks and their content.

**New function `cmd_verdicts_export(args, map_data)`:**
Arguments: args (parsed), map_data (from `_parse_map(MAP_MD)`)

Step 1 — Read verdicts:
```python
verdicts = _parse_verdicts(VERDICTS_MD)
verdict_rows = verdicts["verdict_rows"]
lead_summary = verdicts["lead_summary"]
```

Step 2 — Determine required IDs (FILLED-NEEDS-CHECK + BLOCKED from main map):
```python
required_ids = {

}
```

Step 3 — Validate (fail fast with full list of problems):
Collect all errors into a list, then if any exist: print each on its own line, sys.exit(1).

Checks:
a. Missing verdict rows: `required_ids - {r["map_id"] for r in verdict_rows}` → error for each
b. Duplicate verdict rows: any map_id appearing more than once → error for each duplicate
c. Invalid verdict values: any `verdict` not in VALID_VERDICT_VALUES → error
d. Invalid evidence types: split each `evidence_types` field on `|` or `,`, strip, check each against VALID_VERDICT_EVIDENCE_TYPES → error for any invalid
e. MISMATCH/PARTIAL without D-191-NN: any row where verdict in {"MISMATCH","PARTIAL"} and decision_id is blank or "—" → error
f. D-191-NN not in AM-MAP-03: for each non-blank decision_id in verdict_rows, check it exists in `{d["decision_id"] for d in map_data["team_decisions"]}` → error if absent
g. Missing Lead Summary entries: check leads L1..L9 all have an entry in lead_summary → error for missing
h. MATCH verdict resting only on PLANNING-DOC: if all evidence types for a MATCH row are "PLANNING-DOC" → warning (not error) — print but do not exit
