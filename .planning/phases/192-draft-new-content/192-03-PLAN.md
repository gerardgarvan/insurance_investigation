**REG — First-Line Regimen Labeling**
Expected: assignment of regimen label to first treatment episode.
Code: Phase 61 — locate the actual script and cite it. If no single defining function,
cite the script-level logic with line range.

**EPI — Treatment Episodes**

(Phase 142, 164 context). DEC-007 (90-day relapse/refractory threshold) is CONFIRMED.

**ANT — Anthracycline Exposure**
Expected: anthracycline flag derived from chemo data.
Code: locate defining file from Phases 166, 187, 188. Cite function and line range.
If the Phase 188 code introduced a new variable, note it under Cleaning Rules Applied.

**CBC — Complete Blood Count Definition**
Expected: CBC encounter definition for survivorship monitoring.
Code: `build_cbc_events()` in `R/utils/utils_distance_cbc.R`. Cite line range.

**RUR — Rurality**
Expected: RUCA and/or RUCC classification using ZIP code.
Code: Phase 116 script — locate and cite. DEC-006 (RUCA can use 5-digit ZIP) is CONFIRMED;
cite it under Cleaning Rules Applied.

**SDI — Social Deprivation Index**

Code: Phase 144 script — locate and cite. External reference file: SDI (cite as
RECEIVED event type from §1).

**DOI — Rituximab/Methotrexate Diagnoses of Interest**
Expected: secondary diagnosis codes that distinguish rituximab vs methotrexate indication.
Code: `DOI_CODE_MAP` in `R/utils/utils_doi.R`. Cite the constant and its line range.

**CLS — HL vs NHL Classification**
Expected: classification of patients as HL vs NHL using ICD codes and team decisions.
Code: `R/utils/utils_cancer.R` — locate the HL/NHL classification function. DEC-009
(NHL-only episodes removed) and DEC-010 (err on side of inclusion) are CONFIRMED.

Code: Phase 62/113 — locate the actual script. Cite `resolve_death_date()` in
