<grammar>

## AM-DRAFT.md grammar (authoritative for Plans 02 and 03)

**Header:** first lines are `# AM-DRAFT` and `<!-- commit: <sha> -->`.

**Sections:** level-2 headings reproduce the manual's section headings verbatim (e.g., the exact
text of the manual's §4 heading). Appendix headings likewise. Draft-only helpers are level-2
headings starting `## Not drafted` (reasons for any EMPTY-REPO-CAN-ANSWER ID not drafted).

**§4 layout:**
```
## <manual §4 heading>
### <existing domain heading, verbatim from the manual>     (one per existing domain touched)
...units and directives...
<!-- BEGIN REPO-ONLY DOMAINS -->
### <Domain name> {#S4-XXX}                                  (one per repo-only domain)
#### Expected Structure
#### Observed Issues
#### Cleaning Rules Applied
#### Unresolved Issues
<!-- END REPO-ONLY DOMAINS -->
```

**Bullet unit** (one statement):
```
- [S4-CBC-01] Statement text.
  STATUS: DRAFTED
  CITE: R/utils/utils_distance_cbc.R:build_cbc_events():L20-L58
```
`STATUS:` and `CITE:` lines belong to the bullet directly above them, indented two spaces. A unit
with several sources has several `CITE:` lines. `CITE:` is required for DRAFTED and CORRECTION,
optional otherwise.

**Table unit:** every draft table keeps the manual's columns and appends three trailing columns
`Map ID | Status | Cite`. Phase 193 removes the trailing columns. Multiple cites separated by `; `.

**Correction directive:**
```
#### CORRECTION <map ID>
- Target: <section> / <map ID>
- Anchor: "<exact current text>" (AnalyticManual_2026.01.30.md:L<n>)
- Action: REPLACE | INSERT-AFTER | MARK-SUPERSEDED
- Replacement: <text>
- Provenance: <decision IDs>
  STATUS: CORRECTION
  CITE: <citation>
```

**Status values:** `DRAFTED`, `CORRECTION`, `TEAM-INPUT-NEEDED`, `OPEN-QUESTION-SEE-§8`.

**Citation forms (each `CITE:` value must match one):**
- code/config: `<repo path>:<function()>|<KEY>:L<a>-L<b>`
- workbook sheet: `am_verification_<YYYYMMDD>.xlsx:<SHEET>`
- decision: `DEC-<nnn>` or `D-<nnn>-<nn>` (must exist in AM-MAP-03)
- planning document (history only): `.planning/phases/<dir>/<file>.md`
- manual or notes: `docs/analytic_manual/<file>.md:L<a>-L<b>`

**§8 table:** manual columns `Item | Notes | Date added` plus the trailing three. Notes begins with
`MISMATCH; ` or `OPEN-DEPENDENCY; ` followed by the IDs (e.g., `MISMATCH; D-191-06; S4-DTH-03`).
MISMATCH Item text matches `^Manual: .+\. Code: .+\. Which should the manual record\?$`.

</grammar>
