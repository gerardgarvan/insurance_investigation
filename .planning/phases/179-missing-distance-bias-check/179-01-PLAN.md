<task type="auto">

  <action>
    **Section 2 — patient-years (D-01, D-03, D-04)**
    ```r
    py <- anchors |>
      dplyr::filter(!is.na(hl_anchor_date)) |>
      dplyr::mutate(k_max = as.integer(floor(as.numeric(CDM_CUTOFF - hl_anchor_date) / 365))) |>
      dplyr::filter(k_max >= 1L) |>
      tidyr::uncount(k_max, .id = "year_index") |>          # year_index = 1..k_max per patient
      dplyr::mutate(year_start = hl_anchor_date + 365L * (year_index - 1L),
                    year_end   = hl_anchor_date + 365L * year_index)
    ```
    No fixed cap. Then death censoring: left-join `death_dates` by ID and drop years with
    `!is.na(death_date) & death_date <= year_end`. Log: patients with anchor, patients with ≥1 full
    year, patient-years before/after death censoring.

    **Section 3 — flags (summarise separately, then left-join back so no patient-year is lost)**
    - 3a `cbc_year`: join `cbc_events` to `py[, ID, year_index, year_start, year_end]` by ID, keep
      `cbc_date > year_start & cbc_date <= year_end`, `distinct(ID, year_index)` → flag 1;
      left-join onto `py`, `coalesce(…, 0L)`.
    - 3b `cbc_year_broad`: same with broad events.
    - 3c Exposure (D-07/D-08): from `enc_distance`, `distance_status == "computed"`, join anchors,
      `ADMIT_DATE > hl_anchor_date` (and ≤ CDM_CUTOFF); per ID `median_distance`. Join onto `py`.
      `exposure_missing <- is.na(median_distance)`;
      `far <- dplyr::if_else(exposure_missing, NA_integer_, as.integer(median_distance > CUTOFF))`.
    - 3d `far_year_median` (D-09): per (ID, year_index) median over computed encounters with
      `ADMIT_DATE > year_start & ADMIT_DATE <= year_end`; NA if none; then `as.integer(> CUTOFF)`.
    - 3e Triage: left-join R/121; NA → "not in R/121".
    - 3f Validate: `nrow(py_final) == nrow(py)` after death censoring; no duplicate (ID, year_index);
      cbc flags in {0,1}; `all(is.na(far[exposure_missing]))`; `all(year_end <= CDM_CUTOFF)`.
    - 3g `saveRDS(py_final, file.path(CONFIG$output_dir, "internal", glue("cbc_patient_year_{RUN_DATE}.rds")))`
      (create dir). Columns: ID, year_index, year_start, year_end, cbc_year, cbc_year_broad,
      median_distance, far, far_year_median, exposure_missing, triage.
