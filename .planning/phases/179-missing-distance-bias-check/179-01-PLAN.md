### Task 2: Build patient-year table with exposure and outcome flags (Sections 2–3)

**File:** `R/179_cbc_patient_year.R` (append to same file)

**Action:** Write Sections 2 and 3.

**Section 2 — Patient-year expansion (D-01, D-03, D-04):**

Start from `anchors` — all patients with known `hl_anchor_date` (inner join drops the NA-anchor
patients; log count dropped).

For each patient, generate year indices k = 1, 2, 3, ... up to a maximum of 10 (guard against
runaway). Year k interval: `year_start = hl_anchor_date + 365*(k-1)`, `year_end = hl_anchor_date + 365*k`.
The interval is half-open: `(year_start, year_end]`; anchor day is pre (D-01 "anchor day = pre").
In R: `year_start < event_date & event_date <= year_end`.

Use `tidyr::crossing()` or `dplyr::reframe()` to expand:
```r
py_raw <- anchors |>
  dplyr::filter(!is.na(hl_anchor_date)) |>
  dplyr::mutate(year_index = list(1:10)) |>
  tidyr::unnest(year_index) |>
  dplyr::mutate(
    year_start = hl_anchor_date + 365L * (year_index - 1L),
    year_end   = hl_anchor_date + 365L * year_index
  )
```

Apply D-04 fully-observed-year filter — keep only rows where:
- `year_end <= CDM_CUTOFF` (year must be complete at cutoff), AND
- patient was alive at `year_end` (if DEATH table present: `is.na(death_date) | death_date > year_end`).

Log: n patient-years before filter, n dropped for cutoff, n dropped for death, n remaining.

**Section 3 — Outcome and exposure flags:**

3a. **Primary CBC outcome (D-05, cbc_year):** left-join `cbc_events` onto `py_raw` by ID,
    filter `cbc_date > year_start & cbc_date <= year_end`, group by (ID, year_index),
    summarise `cbc_year = as.integer(any(!is.na(cbc_date)))`, coalesce to 0L for non-joining rows.

3b. **Broad hematology outcome (D-06, cbc_year_broad):** same logic with `broad_events`.

3c. **Primary exposure (D-07, D-08):** from `enc_distance`, keep only
    `distance_status == "computed"` and `ADMIT_DATE > hl_anchor_date` (post-anchor).
    Join to anchors by ID to get hl_anchor_date.
    Per patient: `median_distance = median(distance_mi, na.rm = TRUE)`.
    Patients with zero qualifying encounters → `median_distance = NA_real_`.
    Flag `exposure_missing = is.na(median_distance)`.
    Flag `far = as.integer(!is.na(median_distance) & median_distance > CUTOFF)`.
    Log: n patients with computed exposure, n with exposure_missing.

3d. **Per-year sensitivity exposure (D-09, far_year_median):** per (ID, year_index),
    median of computed-distance encounters where `ADMIT_DATE > year_start & ADMIT_DATE <= year_end`.
    NA if no qualifying encounters in that year. Carry as `far_year_median` (integer 0/1 or NA).

3e. **Triage join:** left-join `r121_triage` by ID. NA → `"not in R/121"` as documented in D-17.

3f. **Assemble final patient-year RDS (D-17):** one row per patient-year:
    Columns: ID, year_index, year_start (Date), year_end (Date), cbc_year (int),
    cbc_year_broad (int), median_distance (dbl), far (int, NA if exposure_missing),
    far_year_median (int or NA), exposure_missing (lgl), triage (chr).

    Validate: nrow == n_py_remaining (from Section 2 filter); no duplicate (ID, year_index) pairs.

    Write RDS:
    ```r
    rds_path <- file.path(CONFIG$output_dir, "internal",
      glue("cbc_patient_year_{RUN_DATE}.rds"))
    dir.create(dirname(rds_path), showWarnings = FALSE, recursive = TRUE)
    saveRDS(py_final, rds_path)
    message(glue("  Internal RDS written: {rds_path}"))
    ```
