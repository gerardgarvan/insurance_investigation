<objective>
Add missing drug-name alias entries to `DRUG_NAME_ALIASES` in `R/00_config.R` so that
salt and acid variants of ABVD-regimen drugs (vinblastine sulfate, vincristine sulfate,
bleomycin sulfate, dacarbazine) collapse to a single canonical display name per the
same pattern as the existing doxorubicin entries.

Purpose: Colleague flagged "Vinblastine" and "Vinblastine Sulfate" appearing as separate
tokens in `drug_names` on the same Gantt row. The root cause is that the RxNorm lookup
path yields "vinblastine sulfate 1 MG/ML Injectable S" for CUI 239178, while
MEDICATION_LOOKUP (via J9360/67228/11198) yields "Vinblastine". `canonicalize_drug_name()`
already handles this pattern for doxorubicin — it just needs entries for the other drugs.

Output: Updated `R/00_config.R` with vinblastine alias + audited entries for other
ABVD-class salt variants. No other files change.
</objective>

canonicalize_drug_name <- function(x) {
  key <- tolower(stringr::str_trim(x))
  hit <- DRUG_NAME_ALIASES[key]
  out <- ifelse(!is.na(hit), unname(hit), x)
  out[is.na(x)] <- NA_character_
  out
}
