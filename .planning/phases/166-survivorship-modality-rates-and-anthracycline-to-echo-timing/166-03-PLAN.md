  <behavior>
    All inputs are tibbles keyed on ID.
    - last_anthracycline_dose(episodes, drugs): episodes (ID, drug_name collapsed, admin_date, first_line, episode_id). Returns one row per ID with any included drug: last_dose_firstline_dt (max admin_date where drug_name %in% drugs & first_line), last_dose_ever_dt (max over all included-drug rows). No first-line rows → last_dose_firstline_dt NA.
    - echo_time_to_event(doses, echo_events, followup, deaths, dose_col = "last_dose_firstline_dt"): joins by ID. Keeps patients with non-NA dose_col. Excludes follow_end <= dose (returned as attribute / list element n_no_time_after_last_dose). first_echo = min event_date > dose (strict). If first_echo exists and <= follow_end → event "echo", time = first_echo - dose. Else if death_date_resolved > dose and <= follow_end → "death", time = death - dose. Else "censored", time = follow_end - dose. event_factor levels exactly c("censored", "echo", "death").
    - echo_cif_km(tte, horizons = c(365, 730, 1825)): AJ fit `survfit(Surv(time, event_factor) ~ 1)`; take the echo column by matching "echo" in fit$states; `summary(fit, times = horizons, extend = TRUE)` and set CIF to NA for horizons > max observed time. 1 − KM from `survfit(Surv(time, event_factor == "echo") ~ 1)` at the same horizons, same NA rule. Return horizon_days, cif_aj, one_minus_km, n_risk (from the AJ summary), with the 1 − KM column labelled "overestimate: deaths censored".
    - echo_rate_post_dose(doses, echo_events, followup, dose_col): per ID, echoes with dose < date <= follow_end divided by (follow_end − dose)/365.25; NA_real_ when person-time <= 0. Output ID, modality = "echo_post_anthracycline", n_dates_post, person_years, rate_per_py (same shape as Plan 02's long table).
  </behavior>
