**D-03 / D-04 — Build ZIP5→modal-ZIP9 lookup (adapt R/106 lines 597-609):**
```r
zip5_lookup <- addr_raw |>
  mutate(
    zip9_norm       = normalize_zip9(ADDRESS_ZIP9),
    zip5_norm       = normalize_zip5(zip9_norm),
    period_start_dt = parse_pcornet_date(ADDRESS_PERIOD_START)
  ) |>
  filter(!is.na(zip9_norm), !is.na(zip5_norm)) |>
  group_by(zip5_norm, zip9_norm) |>
  summarise(
    freq        = n(),
    latest_date = suppressWarnings(max(period_start_dt, na.rm = TRUE)),
    .groups = "drop"
  ) |>
  group_by(zip5_norm) |>
  arrange(desc(freq), desc(latest_date), .by_group = TRUE) |>
  slice(1) |>
  ungroup() |>
  select(ZIP5 = zip5_norm, modal_zip9 = zip9_norm)
```
This groups by ZIP5 (not by patient ID as in R/106) — one modal ZIP9 per ZIP5 across all
patients in LDS_ADDRESS_HISTORY.
