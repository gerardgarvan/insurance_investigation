  <behavior>
    assign_regimen(date_level_df, regimen_dict, window_days):
    - Input: data frame with columns (ID, treatment_date, treatment_type, canonical_drug) — one row per drug-date administration
    - Groups by (ID, episode_number) where episode_number comes from R/26/28 staged output
    - Within each episode, collects all canonical drugs administered within window_days of episode start_date
    - Matches against REGIMEN_DICT: for each family in order, checks if all required drugs present; if exclusive=TRUE also checks no other chemo drug present
    - Returns the first matching family name, or "Other" if none match
    - Output: one row per episode with column regimen_label (character)

    assign_lot(episode_df, lot_gap_days, maintenance_classes, sct_dates_df):
    - Input: episode_df with columns (ID, episode_number, start_date, regimen_label); sct_dates_df with (ID, sct_date)
    - Sorts episodes per patient by start_date
    - LOT counter starts at 1 for first episode
    - Increments LOT when: gap from prior episode end_date >= lot_gap_days AND new episode regimen_label is not in maintenance_classes; OR episode start_date > any sct_date for the patient
    - Maintenance episodes (regimen_label in maintenance_classes) inherit the current LOT, do not increment
    - Returns episode_df with added column line_of_therapy (integer)
  </behavior>
