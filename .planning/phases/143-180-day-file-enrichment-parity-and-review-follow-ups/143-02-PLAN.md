<objective>
Parameterise R/28_episode_classification.R so it can enrich the 180-day episodes file without being called twice or duplicated. Wire the 180-day enrichment call. Verify the 90-day output is byte-identical to before.

Purpose: The six blank enrichment columns in gantt_episodes_180.csv exist because R/142_gantt_180_export.R reads treatment_episodes_180.rds, which bypasses R/28. The fix is not a copy of R/28 — it is adding parameters so R/28 can be called with a different input RDS. The 90-day defaults must remain unchanged.

Output: R/28 accepts `episodes_rds_path` (default = 90-day path) and `out_suffix` (default = ""). Running it with `out_suffix = "_180"` produces treatment_episodes_180_enriched.rds. The 90-day treatment_episodes.rds is byte-identical to its pre-change state.

    **Step 1 — Add parameters near the top of the script (after the source() calls, before SECTION 1):**

    Add these three lines immediately after the existing path declarations (around line 98-100):

    ```r
    # Phase 143: parameterisable path and suffix so this script can enrich the 180-day
    # episodes file without being duplicated. Defaults reproduce 90-day behaviour exactly.
    EPISODES_RDS_PATH <- getOption("p143_episodes_rds",
                                    file.path(CONFIG$cache$outputs_dir, "treatment_episodes.rds"))
    DETAIL_RDS_PATH   <- getOption("p143_detail_rds",
                                    file.path(CONFIG$cache$outputs_dir, "treatment_episode_detail.rds"))
    OUT_SUFFIX        <- getOption("p143_out_suffix", "")
    ```

    Use `getOption()` with defaults rather than function arguments — this script is sourced by R/39, not called as a function, so options are the correct parameterisation mechanism for a sourced script.

    **Step 2 — Replace the two hardcoded readRDS calls:**

    Replace:
    ```r
    episodes <- readRDS(OUTPUT_RDS)
    ```
    with:
    ```r
    episodes <- readRDS(EPISODES_RDS_PATH)
    ```

    Replace the DETAIL_RDS readRDS call with DETAIL_RDS_PATH. Find all readRDS(OUTPUT_RDS) and readRDS(DETAIL_RDS) in the file and substitute the new path variables. Do not change OUTPUT_RDS or DETAIL_RDS themselves — they are used in the message() calls and in the final saveRDS, and those references will be updated in the next step.

    **Step 3 — Fix the output path:**

    Locate the final saveRDS call. It currently writes back to OUTPUT_RDS (the 90-day path). Change it to:

    ```r
    out_rds <- file.path(CONFIG$cache$outputs_dir,
                         paste0("treatment_episodes", OUT_SUFFIX, ".rds"))
    saveRDS(episodes, out_rds)
    message(glue("  Saved enriched episodes to: {out_rds}"))
    ```

    **Step 4 — Fix episode_number join keys:**

    From 143-DISCOVERY.md's join key risk section, every internal join that groups or joins on `episode_number` alone must be changed to use `(patient_id, treatment_type, episode_start)` as the key.

    Specifically:
    - `group_by(patient_id, treatment_type, episode_number)` → `group_by(patient_id, treatment_type, episode_start)`
    - `left_join(..., by = c("patient_id", "treatment_type", "episode_number"))` → `by = c("patient_id", "treatment_type", "episode_start")`
    - `anti_join(..., by = c("patient_id", "treatment_type", "episode_number"))` → same substitution
    - `select(..., episode_number, ...)` where episode_number is being used as a carry-through join key → substitute episode_start

    **Exception:** If any join involves ENCOUNTERID (encounter-level joins against DIAGNOSIS), that join is already safe — ENCOUNTERID is stable across windows. Do not change those.

    After every substitution, verify that `episode_start` is present in the data frame at that point. It is in the input treatment_episodes.rds (confirmed by required_cols at line ~155-156), and it must be selected/retained in any intermediate frames that carry it.

    **Step 5 — Verify 90-day path is unchanged:**

    With OUT_SUFFIX = "" (the default), the final saveRDS writes to:
    `file.path(CONFIG$cache$outputs_dir, paste0("treatment_episodes", "", ".rds"))`
    = `file.path(CONFIG$cache$outputs_dir, "treatment_episodes.rds")`
