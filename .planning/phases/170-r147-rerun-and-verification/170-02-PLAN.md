    # Phase 170 Downstream Pre-Flight Gate (D-06) — DATE-ANCHORED

    Phases 171 (survivorship workbook refresh) and 172 (Phase 164 close-out) MUST open
    their driving R script with this gate. It refuses to run unless the verify log for the
    SPECIFIC run_date being consumed exists AND contains an OVERALL: PASS line, and it reads
    the dated RDS for that same run_date (never a glob). This is fail-safe against a failed
    R/147: when R/147 fails, the afterok dependency blocks the verify job so no new dated log
    is written, and this gate stops rather than passing on a stale previous-run log.

    How run_date is obtained: the job chain that submits R/147/verify sets an environment
    variable VERIFY_RUN_DATE=$(date +%Y%m%d) at submission time, exported into the downstream
    job. The downstream script reads it from the environment. If it is unset (e.g. ad-hoc
    local run), fall back to today's date explicitly — but still require the dated log.

    ```r
    # ---- Phase 170 pre-flight gate (D-06, date-anchored) ----
    run_date <- Sys.getenv("VERIFY_RUN_DATE", unset = format(Sys.Date(), "%Y%m%d"))
    stopifnot(grepl("^[0-9]{8}$", run_date))

    verify_log <- file.path("output", "logs",
      sprintf("147_verify_vs_1006_%s.txt", run_date))
    if (!file.exists(verify_log))
      stop(sprintf(
        "No verify log for run_date %s at %s. R/147/verify did not complete for this run (afterok blocks verify on an R/147 failure). Re-run Phase 170.",
        run_date, verify_log))

    log_lines <- readLines(verify_log)
    if (!any(grepl("^OVERALL: PASS$", log_lines)))
      stop(sprintf("Verify for run_date %s did not pass. Fix R/147 output before running this script.", run_date))
    message("Phase 170 gate OK (date-anchored): ", basename(verify_log))

    # Consume the RDS for the SAME run_date explicitly (never a glob):
    rds_path <- file.path(CONFIG$cache$outputs_dir,
      sprintf("surveillance_patient_modality_dates_%s.rds", run_date))
    if (!file.exists(rds_path))
      stop(sprintf("Dated RDS for run_date %s not found: %s", run_date, rds_path))
    # ---- end gate ----
    ```

    Notes:
    - The verify log is produced by R/147_verify_vs_1006.R at
      output/logs/147_verify_vs_1006_<run_date>.txt (Phase 170 Plan 01, D-05).
    - The OVERALL line is written by the verify script's final block (always, even on

    - VERIFY_RUN_DATE is set once when the Phase 170 job chain is submitted and carried
