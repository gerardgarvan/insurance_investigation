# Phase 192.4 — Distance × CBC: telehealth exclusion, payer reconciliation, source-composition reporting

## Why this phase exists

Review of `distance_cbc_association_20261110.xlsx` found that the primary encounter-level result
(Rao-Scott OR 0.553, 95% CI 0.472–0.648, whole record) is driven largely by data-source composition:

| Window | Source | Encounters | % of encounters | % far (>100 mi) | % with CBC |
|---|---|---|---|---|---|
| Whole record | Claims (FLM) | 1,196,869 | 67.9% | 19.5% | 5.8% |
| Whole record | Non-claims | 566,801 | 32.1% | 9.9% | 28.5% |
| Post-anchor | Claims (FLM) | 909,297 | 66.3% | 20.1% | 6.3% |
| Post-anchor | Non-claims | 463,014 | 33.7% | 10.0% | 29.8% |

- FLM (Florida Medicaid claims) carries no lab results; CBCs attach to FLM encounters only via same-date
  matching to partner-site labs.
- Far encounters are ~2x as likely to be FLM encounters, so the pooled OR mostly contrasts claims vs
  non-claims encounters.
- Non-claims only (D_excl_FLM): OR 1.122 (0.987–1.276), p = 0.078; post-anchor 1.136 (0.992–1.300), p = 0.065.
- Patient-level MH (BY_SOURCE_pat): OR 0.920 (0.810–1.046) whole record; 0.976 (0.868–1.096) post-anchor.

This is consistent with the team's stated hypothesis (CBC missing at far encounters because it was
obtained outside the captured system), but it means the primary OR should not be read as a distance
effect on CBC receipt. Choice of primary analysis remains with Amy and Erin (D-165-01, D-165-07).

## Scope

In scope (R/165 only):
1. Exclude telehealth (ENC_TYPE == "TH") from primary and sensitivity analyses by default.
2. Reconcile the missing-payer counts (QC vs C_sensitivity).
3. Add a source-composition sheet (claims vs non-claims) to the workbook.
4. Report CI and p for the FLM-excluded estimate on SUMMARY.
5. Blank non-estimable BY_SOURCE strata instead of printing OR 0.000 / CI 0–Inf / p 1.000.
6. Add a CBC-attribution sensitivity flag (one CBC counted once) — reported, not primary.

Out of scope:
- Changing the primary method or making D_excl_FLM primary (pending Amy/Erin).
- Clustering-aware per-site tests in BY_SOURCE_enc* (D-165-06 stays open).
- Patient-year analysis (Phase 179 / R/179).

## Decisions

- **D-192.4-01 (D-165-09) Telehealth.** New `CONFIG$exclude_telehealth` (default TRUE). TH encounters carry
  provider ZIP, so distance does not reflect patient travel. Primary, C_sensitivity, D_excl_FLM, BY_SOURCE*
  all exclude TH. SUMMARY keeps one comparison row `SENS_with_TH` reproducing the 20261110 primary
  (telehealth included). KEY records N excluded per window (expected ≈22,119 whole / 18,793 post).
- **D-192.4-02 (D-165-10) Payer reconciliation.** Per D-165-06, unmatched/NA payer is recoded to "Missing"
  before fitting, so "N dropped (missing payer)" in C_sensitivity must be 0. Current run shows 104,498
  dropped vs QC N_missing_payer 149,651. Find the cause (NA vs unmatched vs label mismatch), fix, and add
  `stopifnot(qc_missing_payer == sum(model_frame$PAYER_CATEGORY_PRIMARY == "Missing"))` (post-TH-exclusion).
- **D-192.4-03 Source composition sheet.** New sheet `E_source_composition`: per window, claims (SOURCE_raw in
  CONFIG$claims_source_codes) vs non-claims — N encounters, % of encounters, n/% far, n/% with CBC,
  plus % of far encounters that are claims. Raw counts; existing suppression rule applies. Sheet guide in KEY updated.
- **D-192.4-04 SUMMARY completeness.** Add `ExclFLM_CI`, `ExclFLM_p` (and `MH_pat_OR`, `MH_pat_CI`, `MH_pat_p`
  from BY_SOURCE_pat MH_POOLED) so the composition-sensitive estimates sit beside the primary.
- **D-192.4-05 Non-estimable strata.** In all BY_SOURCE* sheets, rows with a zero row or column total show
  blank OR/CI/p and `estimable = FALSE`; MH exclusion rule unchanged.
- **D-192.4-06 CBC attribution sensitivity.** Current match attaches a CBC to every encounter whose
  [ADMIT_DATE, DISCHARGE_DATE] contains the lab date, so one CBC can count for several same-day encounters.
  Add sensitivity `SENS_cbc_attributed`: each CBC (patient + date) assigned to one encounter — prefer
  non-claims, then same SOURCE as the lab, then earliest ADMIT_DATE. Report OR in SUMMARY; primary
  definition unchanged (locked R/147 CBC definition).

## Success criteria

2. C_sensitivity "N dropped (missing payer)" = 0, and the payer assert passes.
3. E_source_composition reproduces the table above for the TH-included comparison run (± TH counts).
4. SUMMARY shows primary, adjusted, ExclFLM (OR/CI/p), MH_pat (OR/CI/p), SENS_with_TH, SENS_cbc_attributed.
5. No BY_SOURCE* row prints OR 0.000 or CI upper "Inf".
6. Smoke test R/88 passes.
