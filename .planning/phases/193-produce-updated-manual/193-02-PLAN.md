    - DRAFTED → empty field: action `INSERT-PARA`, target kind `field`.
    - DRAFTED → populated field: action `INSERT-PARA`, target kind `field`; insert AFTER the last existing paragraph of that field (never duplicate existing text — M1/M2).
    - DRAFTED → repo-only new domain (unit whose map ID is in a repo_only_blocks domain): action `INSERT-PARA`, target kind `new_subsection`, using an existing Heading2 style (no new styles).

    - DRAFTED → §8 table: §8 has no table (preflight), so emit ONE `INSERT-TABLE` op carrying all §8 rows (columns Item | Notes | Date added only — Map ID/Status/Cite stripped per D-34 and RESEARCH Open Question 2).
    - TEAM-INPUT-NEEDED → action `PLACEHOLDER`, insert_text `"[TEAM INPUT NEEDED]"`, same destination as its DRAFTED sibling would have.
    - OPEN-QUESTION-SEE-§8 → empty field: action `INSERT-PARA` PLUS a paired `COMMENT-ONLY` op pointing to the §8 row. OPEN-QUESTION-SEE-§8 → existing text: single `COMMENT-ONLY` op, no text change.
    - CORRECTION → action `REPLACE`: carries anchor_text, insert_text (replacement), comment_text citing decision_id + evidence.
    - c0 reply / c1 reply → action `REPLY`: anchor_text = the original comment's anchor; comment_text from D-14 (c0: "OneFLquestions document not received; listed as open in §8 (D-190-01)."; c1: the Phase 191 verdict in one-two sentences covering Tumor Registry default then first HL code date, adding "see §8" if a mismatch — read the c1 verdict from AM-VERDICTS.md). target kind `comment_anchor` with the parent comment's body paraId recorded in a `parent_para_id` field.
