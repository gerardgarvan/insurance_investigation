# Plan 197-07 — Small Fixes

## Objective

Two small code correctness fixes identified during Phase 196-A close-out:
1. `R/tools/check_cohort_fingerprint.R` has the wrong path for `cohort_final.rds`.

   `dirname(CONFIG$cache$outputs_dir)`).
