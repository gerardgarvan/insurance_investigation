# 197-11: Correctness fixes — first-line fan-out (R/29) and Hodgkin label mismatch (R/28)

## Decisions

**D-197-11-01**: `HL_CANCER_CATEGORIES` constant in `00_config.R`.
- Defined as `c("Hodgkin Lymphoma (non-NLPHL)", "NLPHL")` immediately after `CANCER_SITE_MAP` closes (~line 1237).
- All `is_hodgkin` derivations and HL tie-break `arrange()` calls must use `%in% HL_CANCER_CATEGORIES`.
- Never compare against the bare string `"Hodgkin Lymphoma"` as a category value.

**D-197-11-02**: R/28 four-site fix.
- Lines 209, 241 (tie-break arrange): `== "Hodgkin Lymphoma"` → `%in% HL_CANCER_CATEGORIES`.
- Line 264 (is_hodgkin mutate): `== "Hodgkin Lymphoma"` → `%in% HL_CANCER_CATEGORIES`.
- Line 276 (second-cancer filter): `!= "Hodgkin Lymphoma"` → `!(... %in% HL_CANCER_CATEGORIES)`.
- Guard added after is_hodgkin is set: `stop()` if `sum(is_hodgkin) == 0`.
- R/30 (investigation, same logic): two parallel arrange() calls fixed identically.

**D-197-11-03**: R/29 first-line join key fix.
- Root cause: `first_line_ids` carried only `(patient_id, episode_number)`; `episode_number` restarts
  within each `treatment_type`, so the join back to `episodes` (all treatment types) set
  `is_first_line = TRUE` on same-numbered episodes of every type.
- Fix: `first_line_flags` and `first_line_ids` now carry `treatment_type`; join key is
  `(patient_id, treatment_type, episode_number)`.
- Two additional pre-write guards added (guards 5 and 6):
  - Guard 5: `is_first_line TRUE` only on `treatment_type == "Chemotherapy"` rows with non-NA
    `regimen_label`; `stop()` if any violation.
  - Guard 6: exactly one `is_first_line TRUE` per patient; `stop()` if any patient has > 1.
