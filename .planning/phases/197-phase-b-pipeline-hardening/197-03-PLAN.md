# Plan 197-03 — Pin Unpinned Latest-File Picks

## Objective

22 scripts use `list.files()` / `file.mtime()` to pick the "latest" dated output.
Wrong file is silently consumed if multiple dated files exist.

Pattern (from R/166, the reference implementation):
- Env var `R<NNN>_<INPUT>` overrides the path.
- If unset: resolve latest file, `message("(pinned=FALSE)")`.
- If set: use it, `message("(pinned=TRUE)")`.
- `stop()` if the resolved path does not exist.

Extract this into a single `resolve_input()` helper so it is not copy-pasted.

Priority:
1. High-risk (delivered-output assemblers): R/162, R/163, R/167, R/168, R/180, R/183
2. Remaining scripts from the audit list

### Task 1 — Create resolve_input() in R/utils/utils_io.R

Create or extend `R/utils/utils_io.R` with:

```r
#' Resolve a dated input file path with optional env-var pin.
#'
#' @param dir       Directory to search.
#' @param pattern   Glob/regex pattern matching the dated files.
#' @param env_var   Name of env var that overrides the path (e.g. "R183_R122_RDS").
#' @param label     Short label for messages (e.g. "payer_summary").
#' @return          Absolute file path (stops if not found).
resolve_input <- function(dir, pattern, env_var, label = env_var) {
  override <- Sys.getenv(env_var, unset = "")
  if (nchar(override) > 0) {
    path <- override
    if (!file.exists(path))
      stop("[resolve_input] ", label, ": pinned path not found: ", path)
    message("[resolve_input] ", label, " (pinned=TRUE): ", path)
    return(path)
  }
  candidates <- sort(list.files(dir, pattern = pattern, full.names = TRUE))
  # Version-aware sort: v10 > v2 (pad numeric suffix before sorting)
  ver_key <- function(f) {
    m <- regmatches(f, regexpr("_v(\\d+)(\\.\\w+)?$", f))
    if (length(m) == 0 || m == "") return(0L)
    as.integer(sub("_v(\\d+).*", "\\1", m))
  }
  if (length(candidates) > 1) {
    has_ver <- sapply(candidates, ver_key)
    if (any(has_ver > 0)) {
      candidates <- candidates[order(has_ver, decreasing = TRUE)]
    }
  }
  if (length(candidates) == 0)
    stop("[resolve_input] ", label, ": no file matching '", pattern, "' in ", dir)
  path <- candidates[1]
  message("[resolve_input] ", label, " (pinned=FALSE): ", path)
  path
}
```
