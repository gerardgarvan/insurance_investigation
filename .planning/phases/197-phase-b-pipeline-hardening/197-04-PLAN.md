# Plan 197-04 — Overwrite Protection (versioned_output_path)

## Objective

61 same-date overwrites confirmed by audit. Same-day re-run silently destroys prior output.

Add `versioned_output_path()` to R/utils: when a dated output already exists, writes _v2/_v3...
Controlled by an env var / CONFIG flag (default: version, never silently overwrite).
Apply first to delivered-output writers, then other audit-listed scripts.

### Task 1 — Create versioned_output_path() in R/utils/utils_io.R

Add to `R/utils/utils_io.R` (same file as `resolve_input()`):

```r
#' Return a dated output path, incrementing _v2/_v3... if the base path exists.
#'
#' Controlled by env var VERSIONED_OUTPUT (default "TRUE").
#' Set VERSIONED_OUTPUT=FALSE to disable versioning (stop() if file exists instead).
#'
#' @param dir       Output directory.
#' @param stem      File stem WITHOUT date suffix (e.g. "distance_cbc_association").
#' @param ext       Extension including dot (e.g. ".xlsx").
#' @param run_date  Date string (default: today in YYYYMMDD).
#' @return          Full path string.
versioned_output_path <- function(dir, stem, ext, run_date = format(Sys.Date(), "%Y%m%d")) {
  versioning <- !identical(Sys.getenv("VERSIONED_OUTPUT", unset = "TRUE"), "FALSE")
  base  <- file.path(dir, paste0(stem, "_", run_date, ext))
  if (!file.exists(base)) return(base)

  if (!versioning)
    stop("[versioned_output_path] '", basename(base), "' already exists. ",
         "Set VERSIONED_OUTPUT=FALSE to suppress versioning (will stop).")

  v <- 2L
  repeat {
    candidate <- file.path(dir, paste0(stem, "_", run_date, "_v", v, ext))
    if (!file.exists(candidate)) return(candidate)
    v <- v + 1L
  }
}
```
