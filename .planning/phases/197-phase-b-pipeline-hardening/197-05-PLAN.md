# Plan 197-05 — rxnorm Cache Single Owner

## Objective

Both R/105 and R/131 write/read `rxnorm_ingredient_cache.csv`.
The audit confirmed:
- The append-then-rewrite pattern is functionally safe (no destructive conflict).
- Cold-cache re-query risk: RxNorm API versioning can change `normalized_name`.
- R/131 double-append risk: guard may evaluate against stale `chemo_existing`.

Decision: R/105 is the primary cache owner. R/131 reads the cache (from R/105's output) and
appends MED_ADMIN-exclusive CUIs to `all_codes_resolved_next_tables_v2.1.xlsx` only — it does
NOT write `rxnorm_ingredient_cache.csv`.
