<interfaces>
Output contract consumed by get_zip_centroid() (Plan 01):
```
ZIP9      character, 9 digits, no hyphen, leading zeros preserved
GEOID     character, 12-digit block-group FIPS (state 2 + county 3 + tract 6 + block group 1)
INTPTLAT  double, decimal degrees
INTPTLON  double, decimal degrees (negative for the US)
```
One row per ZIP9. If the Atlas maps a ZIP9 to more than one block group, keep the first by
GEOID order and count the duplicates in the log.

Neighborhood Atlas ZIP+4 file layout (2024 release): the ZIP+4 identifier and the block-group
FIPS column NAMES are not confirmed in this repo — Task 1 inspects a header before anything
is hard-coded. Expect a ZIP+4 identifier that may carry a prefix letter and/or an underscore
between the 5- and 4-digit parts, and a block-group FIPS column alongside ADI_NATRANK /
ADI_STATERNK.
</interfaces>
