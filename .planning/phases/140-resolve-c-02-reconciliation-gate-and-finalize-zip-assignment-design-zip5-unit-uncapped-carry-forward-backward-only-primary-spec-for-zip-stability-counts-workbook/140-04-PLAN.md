Implement 140-CONTEXT.md Section 7's two findings: (P-06b) fold S1 into S3 in the ordered scenario assignment -- S1 buys only 1.7pp and is definitionally entangled with S3 (an encounter eligible only via S1-forward is assigned S1 by the old ordered rule while remaining S3-eligible), so the implementation/documentation cost exceeds the yield; and (P-06a) add an independently-computed backward-only ordered waterfall as a parallel column set on C_completeness, since 92% of S2 occurrences (and the old S1's forward share) are forward-only, and `get_zip9_at_date()` is backward-only by design -- adopting forward lookup as primary would be a methodological change to production, not a coverage patch.

Purpose: 140-CONTEXT.md's recommended specification is Primary = backward-only (already_has_zip9 + S2-backward + S3) at ~86% encounter coverage, Sensitivity = forward-inclusive (full ordered waterfall) at ~96.9% -- agreement between the two preempts the obvious reviewer objection to forward inference, and divergence is itself a reportable finding. Explicitly: "Do not compute the ~86% by summing B_direction_split rows" -- those counts are unordered and overlapping; the backward-only figure requires its own recomputed ordered waterfall (P-06a's whole point).

This plan touches the same SECTION 11/12 logic 140-01/140-03 already amended (SECTION 12/13 QC assembly), so it is sequenced after both (Wave 3) to avoid concurrent-edit conflicts.

```r
assign_scenarios <- function(encounter_zip_flagged, backward_only = FALSE) {
  encounter_zip_flagged %>%
    mutate(
      .s2_test = if (backward_only) s2_backward else s2_either,
      scenario_assigned = case_when(
        has_direct_zip9      ~ "already_has_zip9",
        .s2_test              ~ "S2",
        has_direct_zip5_only  ~ "S3",   # 140-04 P-06b: S1 folded into S3 universally, no separate ordered bucket
        TRUE                   ~ "unresolvable"
      ),
      scenario_assigned = factor(scenario_assigned,
        levels = c("already_has_zip9", "S2", "S3", "unresolvable"))
    ) %>%
    select(-.s2_test)
}
```
