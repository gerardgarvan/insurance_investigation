# 164-01 — Normalize Adriamycin and liposomal variants → Doxorubicin; re-render Gantt charts

## Task 1 (auto) — Inventory
- Grep the repo (case-insensitive) for
  `adriamycin|doxorubicin|doxil|caelyx|liposom` across R/, R/utils/, config, and
  any drug lookup CSV/XLSX.
- Identify every script that renders a Gantt chart, and the upstream step where
  each script gets its drug-name column.
- Check whether a drug-name normalization helper or lookup already exists from
  the Vinblastine fix.
- Record the findings in 164-01-SUMMARY.md: scripts, source columns, and the
  raw string variants observed.

## Task 2 (auto) — Baseline counts
- On HiPerGator, record the following before any change:
  - distinct raw strings mapping to doxorubicin, Adriamycin, or liposomal
    doxorubicin, with row counts;
  - the number of patients and episodes containing each;
  - liposomal rows broken out separately, including the number of
    patient-episodes with both a liposomal and a conventional record in the
    same window.
- Save the results as an RDS/CSV under the phase output folder, for the
  reconciliation step in Task 5.

## Task 3 (auto) — Mapping
- Extend the existing normalizer, or create one shared helper if none exists.
- Use case-insensitive, whitespace-trimmed matching. These strings map to
  `Doxorubicin`:
  - `adriamycin`, `adriamycin pfs`, `adriamycin rdf`, `doxorubicin`,
    `doxorubicin hcl`, `doxorubicin hydrochloride`, `doxil`, `caelyx`,
    `liposomal doxorubicin`, `doxorubicin liposomal`,
    `doxorubicin hcl liposome`.
- Map HCPCS J9000 and J9001 (and any other doxorubicin codes found in Task 1)
  to `Doxorubicin` wherever drug labels are derived from procedure codes.
- Apply the mapping once, at drug-name derivation. Remove any per-chart string
  patches found in Task 1.
- After mapping, deduplicate any patient-episode-drug rows that are now
  identical. Overlapping Adriamycin, liposomal, and Doxorubicin bars merge into
  one.

## Task 4 (auto) — Tests
- Add a testthat file covering:
  - every variant listed in Task 3 maps to `Doxorubicin`;
  - liposomal variants (`Doxil`, `Caelyx`, `doxorubicin liposomal`) map to
    `Doxorubicin`;
  - "ABVD" and other regimen labels pass through unchanged;
  - the mapping is idempotent (normalizing twice gives the same result);
  - duplicate rows collapse after mapping.
- Register the check in R/88_smoke_test_comprehensive.R: the smoke test fails if
  any Gantt input contains `adriamycin|doxil|caelyx|liposom` in its drug-label
  column.

## Task 5 (checkpoint) — HiPerGator run and review
- Sync the changes from the local Windows copy to HiPerGator.
- Re-run the Gantt scripts (90-day and 180-day) under `module load R/4.5`.
- Reconcile against the Task 2 baseline:
  - the count of patients with doxorubicin should be unchanged;
  - the drop in episode/drug rows should equal the brand/generic duplicates plus
    the liposomal/conventional same-window overlaps counted in Task 2.
- Visually confirm every chart: no Adriamycin or liposomal label, and a single
  Doxorubicin row/color.
- Update R/SCRIPT_INDEX.md if helper or script responsibilities changed.
