## Changes Made

### R/00_config.R

- Replaced `icd9 = character(0)` with a 12-entry named character vector sourced from the Rituximab sheet of `Autoimmune Diagnosis codes based on Rituximab and MTX.xlsx`.
- Keys: `7140`, `7141`, `7142`, `7148`, `7149` (RA); `4464` (GPA); `4460` (Polyarteritis nodosa — broader); `6944` (Pemphigus — broader); `71430`, `71432` (Juvenile arthritis); `6961` (Psoriasis); `6960` (Psoriatic arthropathy — added beyond workbook, D-192.2-04).
- `71433` absent (excluded per D-01).
- `AUTOIMMUNE_DX_TYPE_ACCEPT` unchanged.
- Block comment updated: removed 2026-10-29 exclusion language; added Phase 192.2 sourcing note, 71432 override note, and team-review flags for 6960/4460/6944.

### R/utils/utils_doi.R

- Added per-record `code_system` column in the `nrow(q) > 0` branch: `ifelse(DX_TYPE %in% accept$icd9, "ICD-9", ifelse(DX_TYPE %in% accept$icd10, "ICD-10", NA_character_))`.
- Added `autoimmune_dx_code_system` to the `group_by(ID) |> summarise()` call with ICD-9/ICD-10/Both/NA derivation and an inner `stopifnot` guarding against unexpected DX_TYPE values.
- Added `autoimmune_dx_code_system = character(0)` to the empty-q fallback tibble.
- Added a final `dplyr::if_else(has_autoimmune_dx, autoimmune_dx_code_system, NA_character_)` guard to enforce D-04/D-05.
- Added `"code_system NA iff has_autoimmune_dx FALSE"` assertion to the `stopifnot()` invariant block.
- Updated roxygen `@return` to document the new column.

### tests/testthat/test_autoimmune_flags.R

- Updated two stale Phase 192.1 tests that asserted `icd9 slot is empty` and `714.0/'09' -> FALSE` to reflect the Phase 192.2 populated state.
- Added Section 1b: all-12-keys loop test (each key TRUE for DX_TYPE `"09"`, FALSE for `"10"`); `714.33` exclusion test.
- Added Section 2b: six new `summarise_autoimmune_dx` tests covering ICD-10, ICD-9, Both, no-code NA, sentinel-only NA, and mixed-cohort NA-iff-FALSE invariant.
