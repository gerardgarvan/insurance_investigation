## BY_SOURCE_enc / BY_SOURCE_enc_addr — Intentionally Absent

R/181 is patient-level. `cbc_year` is a patient-level flag in `py_raw`; there is no encounter-level CBC variable. No proxy exists. KEY sheet contains the explanation. `grep -c "BY_SOURCE_enc" R/181_cbc_prior_year.R` = 2 (KEY field name and its Value string only — no sheet creation).

## Deviations from Plan

### Auto-fixed

**1. ENCOUNTER SOURCE merged into SECTION 4 (not new SECTION 1b DuckDB block)**
- **Issue:** Plan 03 proposed a new SECTION 1b with its own `open_pcornet_con()`. But R/181 Section 4 already contained an `open_pcornet_con()` call (guard pattern). Two `open_pcornet_con()` calls would violate the single-connection rule.
- **Fix:** Merged ENCOUNTER SOURCE query into Section 4's DuckDB session. Address file load moved to Section 1b (before open). `compute_modal_source_181()` defined in a new Section 2b comment block (helper only, no DuckDB). SOURCE stratification derivation runs in a new Section 4b after the connection closes.
- **Impact:** No behavior change; connection safety rules fully preserved.

**2. prior_primary_src passed directly to build_by_source_pat_sheet_181()**
- **Issue:** Plan code would call `prior_primary_src |> dplyr::left_join(pat_source_181, by = "ID")` inside the sheet builder call site, but `prior_primary_src` already has `SOURCE_analytic_pat` from the assertion-block left_join. A second join would create `SOURCE_analytic_pat.x` / `.y` collision.
- **Fix:** Passed `prior_primary_src` directly (no second join).
- **Impact:** Correct output; assertion still checks `nrow(prior_primary_src) == nrow(prior_primary)`.
