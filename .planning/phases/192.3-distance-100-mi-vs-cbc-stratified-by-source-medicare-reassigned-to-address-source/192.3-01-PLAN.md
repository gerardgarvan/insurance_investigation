## SECTION 1: ENCOUNTER SOURCE freq for HL cohort (DuckDB)

Open a DuckDB connection, query ENCOUNTER.SOURCE for all IDs in enc_distance, close connection.

```r
message("[R/192] Opening DuckDB connection ...")
open_pcornet_con()

hl_ids <- readRDS(ENC_DISTANCE_RDS) |> dplyr::distinct(ID)

# Pull ENCOUNTER.SOURCE for HL cohort IDs — join in R (no IN list in SQL per CLAUDE.md)
enc_source_raw <- duck_query(
  "SELECT ID, ENCOUNTERID, ADMIT_DATE, DISCHARGE_DATE, SOURCE FROM ENCOUNTER"
) |>
  dplyr::semi_join(hl_ids, by = "ID")

close_pcornet_con()
message("[R/192] DuckDB connection closed.")
```

Compute freq table with suppression:
```r
enc_source_freq <- enc_source_raw |>
  dplyr::count(SOURCE, name = "n_encounters", sort = TRUE) |>
  dplyr::mutate(n_display = suppress_display(n_encounters))
```

## SECTION 4: Medicare-sourced encounters in the far/CBC analysis set

Build the enc analysis set with `build_enc_analysis()` to get the exact analytic denominator,
then count Medicare-sourced rows.

```r
enc_distance <- readRDS(ENC_DISTANCE_RDS)
cbc_events   <- readRDS(CBC_EVENTS_RDS)
anchors      <- readRDS(ANCHORS_RDS)

# enc_dates: re-derive from enc_source_raw (already pulled above in Section 1)
# Note: enc_source_raw includes DISCHARGE_DATE from the DuckDB query
enc_dates_for_build <- enc_source_raw |>
  dplyr::mutate(
    ADMIT_DATE     = as.Date(ADMIT_DATE),
    DISCHARGE_DATE = as.Date(DISCHARGE_DATE)
  ) |>
  dplyr::select(ENCOUNTERID, DISCHARGE_DATE, SOURCE)

enc_analysis <- build_enc_analysis(
  enc_distance = enc_distance,
  cbc_events   = cbc_events,
  anchors      = anchors,
  enc_dates    = enc_dates_for_build,
  cutoff       = CONFIG$far_from_care_cutoff_mi
)

n_analysis_total    <- nrow(enc_analysis)
n_analysis_medicare <- sum(enc_analysis$SOURCE %in% PROVISIONAL_MEDICARE_CODES)
pct_medicare        <- round(100 * n_analysis_medicare / n_analysis_total, 1)
```
