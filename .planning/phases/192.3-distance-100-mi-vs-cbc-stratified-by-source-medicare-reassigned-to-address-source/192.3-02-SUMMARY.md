# Phase 192.3 Plan 02: Source Stratification Implementation Summary

**One-liner:** Implemented assign_analytic_source() with temporal-first three-step reassignment chain (address → modal non-claims → Claims_unresolved), seven new BY_SOURCE workbook sheets with Mantel-Haenszel pooled OR and Breslow-Day, and a cell-by-cell regression check against the prior workbook.

## What Was Built

### Task 1: utils_distance_cbc.R

**assign_analytic_source()** — new helper implementing the three-step claims reassignment:
1. Address lookup (temporal rule exactly matching get_zip9_at_date()): interval match first, then recency fallback. SOURCE quality checked AFTER the temporal rule selects the in-effect row — never use a different address row based on SOURCE quality.
2. Modal non-claims SOURCE from enc_all (whole-record, unfiltered). Modal from rows where `SOURCE %in% config$claims_source_codes` is FALSE. Tiebreak: most recent ADMIT_DATE, then alphabetical SOURCE.
3. Claims_unresolved sentinel — kept, not dropped.

Returns enc with four new columns: SOURCE_raw, SOURCE_analytic, source_reassigned (0L/1L), source_reassign_method ("not_reassigned" / "address" / "modal_encounter" / "unresolved").

**build_flm_sensitivity_set()** — un-reassigns FLM rows in enc_with_source (overwriting SOURCE_analytic with SOURCE_raw for FLM encounters). All other strata unchanged. Used by BY_SOURCE_enc_flm and BY_SOURCE_pat_flm.

**build_enc_analysis()** — updated signature: new optional args addr_full, enc_all, config. Step 2b calls assign_analytic_source() when addr_full is non-NULL. Legacy path (addr_full = NULL) renames SOURCE to SOURCE_raw and sets SOURCE_analytic = SOURCE_raw. Step 8 select() now returns SOURCE_raw, SOURCE_analytic, source_reassigned, source_reassign_method.

Unit tests (7 scenarios):
1. Non-claims encounter → not_reassigned, source_reassigned = 0L
2. Claims + interval-match non-claims address → method = address, source_reassigned = 1L
3. Claims + recency-fallback-only address → method = address
4. Claims + no valid address + non-claims enc_all → method = modal_encounter
5. Claims + no valid address + no non-claims enc_all → Claims_unresolved, source_reassigned = 0L
6. Modal tiebreak: most recent ADMIT_DATE wins, then alpha SOURCE
7. **Regression guard:** enc_all broader than enc — modal SOURCE drawn from enc_all MUST differ from modal that would be computed from enc alone
