## New helper: assign_analytic_source()

Add this function to R/utils/utils_distance_cbc.R, immediately before build_enc_analysis().

### Temporal rule for address lookup (CRITICAL — must match get_zip9_at_date() exactly)

The address lookup selects the in-effect row using this two-pass rule:
1. Exact interval match: `ADDRESS_PERIOD_START <= ADMIT_DATE` AND `ADMIT_DATE < ADDRESS_PERIOD_END`
   (open-ended or missing ADDRESS_PERIOD_END is treated as 9999-12-31)
2. Most-recent-before fallback: only used when pass 1 produces no match.
   Select the row with the latest `ADDRESS_PERIOD_START` where `ADDRESS_PERIOD_START <= ADMIT_DATE`.

After selecting the in-effect row via the temporal rule (pass 1 wins over pass 2), THEN check
its SOURCE quality. NEVER skip to an older/different row based on SOURCE quality. NEVER apply
SOURCE quality as a filter during the interval/recency selection. Only after the in-effect row
is identified do we check whether its SOURCE is usable: a row's SOURCE is unusable when it is
missing/blank OR in `config$claims_source_codes`. Unusable SOURCE → fall through to Step 2
(modal). This order is non-negotiable and must be documented in the function comment.

### Function signature

```r
assign_analytic_source <- function(enc, enc_all, addr_full, config)
```

Arguments:
- `enc`: tibble with ID (chr), ENCOUNTERID (chr), ADMIT_DATE (Date), SOURCE (chr).
  Contains the analysis-window rows (may be a filtered subset).
- `enc_all`: tibble with ID (chr), ADMIT_DATE (Date), SOURCE (chr) — ALL cohort ENCOUNTER rows,
  not derived from `enc`. Used exclusively for the whole-record modal SOURCE fallback.
  MUST be the unfiltered cohort ENCOUNTER data passed from the caller, NOT derived from `enc`
  (which may already be restricted to encounters with computed distances).
- `addr_full`: LDS_ADDRESS_HISTORY tibble (character columns). Must contain:
  ID, ADDRESS_PERIOD_START, ADDRESS_PERIOD_END, SOURCE.
- `config`: list with element `claims_source_codes` (character vector).

Returns `enc` with four new columns appended:
- `SOURCE_raw`             — original SOURCE value (never modified)
- `SOURCE_analytic`        — reassigned value used for stratification
- `source_reassigned`      — 0L/1L flag: 1 for method == "address" OR method == "modal_encounter";
                             0 for method == "not_reassigned" OR method == "unresolved"
- `source_reassign_method` — one of: "not_reassigned", "address", "modal_encounter", "unresolved"
                             (character, not factor)

# (Phase 192.3)
#
# Temporal rule (matches get_zip9_at_date() exactly):
#   1. Address lookup: select the in-effect LDS_ADDRESS_HISTORY row at ADMIT_DATE.

#      Pass 2 — most-recent-before: largest ADDRESS_PERIOD_START <= ADMIT_DATE.

#      unfiltered cohort ENCOUNTER table — not derived from enc.
#   3. Unresolved: SOURCE_analytic = "Claims_unresolved". Kept; not dropped.
# ------------------------------------------------------------------------------

```r
# ------------------------------------------------------------------------------
# build_flm_sensitivity_set() -- Sensitivity set for BY_SOURCE_flm sheets
# (Phase 192.3, D-192.3-05)
#
# Tests the "CBC captured outside our system" hypothesis directly.
# Takes the full enc_with_source (output of assign_analytic_source) and returns a

#
# Pass the returned object to the same build_by_source_sheet() helper used for the
# main BY_SOURCE sheets.
# ------------------------------------------------------------------------------
build_flm_sensitivity_set <- function(enc_with_source, config) {
  stopifnot(
    "enc_with_source must be a data.frame"      = is.data.frame(enc_with_source),
    "enc_with_source must have SOURCE_raw"      = "SOURCE_raw" %in% names(enc_with_source),
    "enc_with_source must have SOURCE_analytic" = "SOURCE_analytic" %in% names(enc_with_source),
    "config must have claims_source_codes"      = !is.null(config$claims_source_codes)
  )
  enc_with_source |>
    dplyr::mutate(
      SOURCE_analytic = dplyr::if_else(
        SOURCE_raw %in% config$claims_source_codes,
        SOURCE_raw,          # un-reassign: FLM stays as FLM
        SOURCE_analytic      # all others keep their analytic SOURCE
      )
    )
}
```
