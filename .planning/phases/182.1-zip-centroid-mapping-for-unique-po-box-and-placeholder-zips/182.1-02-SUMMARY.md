## What Was Built

### Task 0 Findings (Read-Only)
- `distance_status` set in `compute_encounter_distance()` (utils_zip_calendar.R:275-280); derived in `case_when` over `zip5_facility` / `zip5_patient` / `distance_mi`.
- Derived columns from `distance_mi` in R/122: `distance_km = distance_mi * 1.609344` (recomputed after fallback for all rows); `distance_km_haversine` computed from centroids (not from `distance_mi` directly — no change needed there).
- `zip_distance()` called on distinct `(zip5_patient, zip5_facility)` pairs with row-count check (`nrow(zd) == nrow(pairs)`) and order check (`identical(zd$zipcode_a, pairs$zip5_patient)`).
- `get_zip_centroid(zips, level = "zip5")` returns tibble with columns `zip`, `level`, `lat`, `lon`, `centroid_source`.
- `build_facility_zip_lookup()` reads `enc_zip_raw` column from the input frame.

### Task 1: Placeholder Step
- Source `utils_zip_crosswalk.R` added in R/122 SECTION 1.
- `hrsa_xwalk <- load_hrsa_crosswalk(CONFIG$hrsa_zip_zcta_path)` in SECTION 2; logs file name and row count; hard stop if absent.
- Before `build_facility_zip_lookup()`: `is_placeholder_facility_zip5()` flags placeholder ZIPs; blanks both `zip5_facility` and `enc_zip_raw` for those rows so they cannot be donors.
- `n_placeholder` logged to console.
- **Test 11** added to `tests/testthat/test-utils-facility-zip.R`: placeholder-blanked key (all `enc_zip_raw = NA`) yields `no_donor`, not `filled_tier1`; `apply_facility_zip_fill()` returns `not_filled` for all rows.

### Task 2: Fallback Tiers
- Inserted after `compute_encounter_distance` join and facility_zip join, before SECTION 5.
- Saves `distance_mi` for all pre-fallback computed rows; asserts unchanged after fallback via `all.equal(..., tolerance = 0)`.
- `status_before` captured; `distance_method` initialized to `"zipcodeR_raw"` for already-computed rows.
- `fb <- which(distance_status == "zip_not_in_db")` — only fallback rows processed.
- **Tier 2**: `map_zip_to_zcta()` on both `zip5_patient` and `zip5_facility`; `coalesce` keeps raw if not in crosswalk; `zip_distance()` on distinct (zp, zf) pairs with row/order guards.
- **Tier 3**: `get_zip_centroid(..., level = "zip5")` on still-NA pairs; `haversine_km(lat, lon) * 0.621371` for miles.
- Recovered rows: `distance_status[fb[ok]] <- "computed"`, `distance_method` set to tier name.
- `status_after` captured; `stopifnot` total row count unchanged and computed count non-decreasing.
- `distance_km` recomputed from `distance_mi * 1.609344` for all rows after fallback.
- `distance_method` included in `enc_distance` RDS select.
