## What Was Built

**R/utils/utils_zip_crosswalk.R** (148 lines): Three pure helper functions:
- `load_hrsa_crosswalk(path)`: reads CSV or xlsx crosswalk, accepts ZIP_CODE/ZIP + ZCTA (case-insensitive), pads both to 5 digits, hard-stops with clear Phase 182.1 message if absent or malformed, returns data.frame(ZIP, ZCTA) unique on ZIP with `source_file` attribute.
- `map_zip_to_zcta(zip5, xwalk)`: delegates normalization to `normalize_zip5_raw()`, matches against xwalk, returns ZCTA or NA.
- `is_placeholder_facility_zip5(zip5, xwalk)`: flags 000xx codes always; flags ZIP3+"00" codes only when absent from the crosswalk (dynamic, no hard-coded list). NA input returns NA.

**R/00_config.R**: Added `hrsa_zip_zcta_path` entry in the Phase 152 geospatial paths section, immediately after `zcta_gazetteer_path`. Annotated with comment directing user to update filename to match staged HRSA file.
