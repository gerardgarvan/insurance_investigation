    Follow R/165's header, sourcing and workbook conventions. Use names found in Task 1; the
    names below are placeholders.

    **0. Setup**: `source("R/00_config.R")` (+ utils_distance_cbc.R if R/165 sources it
    explicitly). RUN_DATE = YYYYMMDD. Outputs:
    `output/temporal_match_sizing_<RUN_DATE>.xlsx`,
    `output/internal/temporal_match_sizing_encounters_<RUN_DATE>.rds`.

    **1. Inputs**: R/121 RDS (default: the run validated in Phase 176; allow override via
    `R177_R121_RDS`), R/122 RDS (default: the file R/165 used; override `R177_R122_RDS`).
    Fall back to most recent only if the pinned file is absent, and say so in KEY.

    **2. Current Phase 165 set**: build exactly as R/165 does → `enc_now`. Counts: encounters
    and patients, whole-record and post-anchor; current far count (> CONFIG$far_from_care_cutoff_mi)
    in each window.

    **3. Candidates**: `patient_zip_missing` encounters that would satisfy every other
    R/165 inclusion rule if they had a distance (apply the same filters minus the
    distance-status one). Attach R/121 triage by patient key (`NA` → "not in R/121").

    **4. Temporal lookup**:
    ```r
    keys <- dplyr::distinct(cand, id = .data[[ID_COL]], d = as.Date(.data[[DATE_COL]]))
    lk   <- get_zip9_at_date(ids = keys$id, dates = keys$d)
    # align by position if one-row-per-input, else join on (id, as.Date(query_date))
    n0 <- nrow(cand)
    cand <- dplyr::left_join(cand |> dplyr::mutate(.d = as.Date(.data[[DATE_COL]])), lk2,
                             by = c(<ID_COL> = "id", ".d" = "d"))
    stopifnot(nrow(cand) == n0)
    cand$coverable <- cand$match_type %in% "interval" & !is.na(cand$ZIP5_matched)
    ```

    **5. Projected distance** for coverable rows using R/122's method (Task 1 item 3) with
    ZIP5_matched and the facility ZIP. Outcomes: projected distance, or `zip_not_in_db`.
    `proj_far = proj_mi > CONFIG$far_from_care_cutoff_mi`.

    **6. Counts** (each whole-record and post-anchor, encounters and patients):
    - current Phase 165 set (denominator); current far
    - context: all Phase 165-eligible encounters of NEEDS_TEMPORAL_MATCH patients
    - candidates; coverable; coverable but zip_not_in_db; filled (coverable with a distance)
    - projected far among filled
    - share filled = filled / current set; far ratio = projected far / current far
    - candidates and filled by R/121 triage group

    **7. D-04 cross-tab**: R/122 `patient_zip_missing` patients by R/121 triage group; count of
    NEEDS_TEMPORAL_MATCH patients with no `patient_zip_missing` encounter. A column
    `definitional_reason` is left blank for the memo author; `d04_explained` is set in Plan 02,
    not here. The script prints the table.

    **8. Decision rule (locked, CONTEXT D-03)**, computed and written to KEY as
    `tier_if_d04_explained`:
    ```r
    share <- max(share_whole, share_post, na.rm = TRUE)
    far_trigger <- isTRUE(far_ratio_whole > 0.05) || isTRUE(far_ratio_post > 0.05)
    tier <- if (share > 0.05 || far_trigger) "New phase" else if (share >= 0.01) "Inline fix" else "Document only"
    ```

    **9. Outputs**:
    - Internal RDS: encounter-level candidates with triage, match_type, coverable, ZIP5_matched,
      proj_mi, proj_far, window flags.
    - Workbook, KEY leftmost (script, run date, input files and whether pinned, cutoff,
      thresholds, share/far ratios, tier_if_d04_explained, confidentiality note);
      A_counts (named rows incl. "Projected >100 mi among filled");
      B_by_triage; C_d04_crosstab. All counts through the existing `suppress_small_vec`;
      percentages computed from unsuppressed counts but shown only when both numerator and
      denominator are ≥ 11.

    No writes to any other path.
