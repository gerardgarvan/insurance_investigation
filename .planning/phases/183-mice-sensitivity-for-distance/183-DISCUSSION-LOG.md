## Imputation Target

| Option | Description | Selected |
|--------|-------------|----------|
| Impute `far` (binary) directly | mice logreg — simple, direct analytic variable | sensitivity only |
| Impute continuous `median_distance`, derive `far` | PMM on log(distance), re-threshold post-imputation | ✓ (primary) |
| Both as separate primary analyses | Doubles output | ✓ (this is what was chosen) |

**User's choice:** Primary = impute `log(median_distance)` via PMM, derive `far = exp(imputed) > 100`. Sensitivity = impute `far` directly via logreg. Imputation at patient level (not patient-year) — the 614 patients are missing their single median distance, so patient-year imputation would allow far to flip between years for the same patient.

**Notes:** User explicitly flagged the patient-level grain as critical. PMM preferred because it only draws from observed values, appropriate for a bounded right-skewed variable.

## Convergence Criteria

| Option | Description | Selected |
|--------|-------------|----------|
| Trace plot inspection only | Visual review, analyst judges — no auto-block | (for plots) |
| Auto-block on hard failures | Stop on NA after imputation, loggedEvents dropping key variables, pooling failure | ✓ |
| Density overlay check only | Block if imputed median is >2x or <0.5x observed | (as diagnostic, not blocking) |

**User's choice:** Hard stops only for: (1) any NA remaining after imputation; (2) loggedEvents dropping `prop_cbc_years` or `dist_to_modal_facility`; (3) pooling failure. Settings: m=20, maxit=20, fixed seed. Trace plots, density overlays, and FMI for the `far` coefficient are produced but not blocking. Under MAR, imputed values legitimately differ from observed — difference alone is not a failure.

**Notes:** User specified Rubin's rules must be implemented manually in code — `mice::pool()` does not support `geeglm`. Use robust (sandwich) SE from geeglm in each imputed dataset.
