    Header per R/122 convention; Outputs = the workbook only (enc_far_from_care.rds is Plan 01's).

    **Section 0 — setup**
    ```r
    source(here::here("R/00_config.R"))
    suppressPackageStartupMessages({ library(dplyr); library(openxlsx); library(glue) })
    METHOD <- CONFIG$distance_assoc_method
    CUTOFF <- CONFIG$far_from_care_cutoff_mi

      "far_from_care_cutoff_mi must be set" = !is.na(CUTOFF)
    )
    if (METHOD == "gee")       library(geepack)
    if (METHOD == "rao_scott") library(survey)
    ```

    **Section 1 — inputs (same helpers as the prototype).** Build `enc` with `build_enc_analysis()`;
    join encounter-level rurality from the R/116 output by ENCOUNTERID and patient-level payer by ID
    (names from DISCOVERY). Record N encounters / patients missing rurality and missing payer.

    **Section 2 — per-window function.** `analyse_window(window)` returns a list with
    `crosstab`, `primary`, `sensitivity`, `qc`:
    - Encounter subset: whole = all; post = `post_anchor == 1`.
    - Patient subset: `build_pat_analysis(window = window)` plus patient-level covariates for the
      patient_fisher sensitivity model: rurality at the patient's latest in-window encounter,
      payer, and modal SOURCE across in-window encounters (ties -> earliest encounter's SOURCE).
    - **Crosstab** (raw integers): encounter-level `far_from_care_100mi x cbc_in_encounter`
      for gee/rao_scott; patient-level `any_far x any_cbc` for patient_fisher. Compute row/column/
      grand totals from RAW counts, then apply display suppression (Section 3).
    - **Primary (unadjusted)**, dispatch on METHOD:
      - gee: `cid <- as.integer(factor(ID))`, arrange by cid, `geeglm(cbc_in_encounter ~ far_from_care_100mi, id = cid, family = binomial(), corstr = CONFIG$distance_gee_corstr)`; robust SE, OR, 95% CI, Wald p, alpha (if exchangeable); DEFF vs `naive_or_se()`
      - rao_scott: `des <- svydesign(ids = ~ID, data = d)`; `svychisq(~far_from_care_100mi + cbc_in_encounter, des, statistic = "F")` (F, df, p); OR/CI/SE from `svyglm(..., family = quasibinomial())`; DEFF vs naive
      - patient_fisher: `chisq.test(ct, correct = FALSE)` and `fisher.test(ct)`; headline Fisher when any expected cell < 5, else chi-square p with Fisher OR/CI
    - **Sensitivity (adjusted: rurality + payer + SOURCE)** on complete cases:
      - gee / rao_scott: same engine, formula `cbc_in_encounter ~ far_from_care_100mi + rurality + payer + SOURCE`
      - patient_fisher: `glm(any_cbc ~ any_far + rurality + payer + modal_source, family = binomial())`
      - Collapse SOURCE / payer levels with < 11 patients into "Other" before fitting (keeps the model estimable and avoids small-cell disclosure in coefficient tables)
      - Report the far_from_care OR, CI, p, and N used / N dropped (by reason: missing rurality, missing payer). Covariate coefficients go below in the same sheet.
      - tryCatch: on failure, record the error message as the result; do not stop the script.
    - **QC counts:** encounters in / dropped (no computed distance, no anchor), patients, telehealth encounters (informational), missing rurality, missing payer, CBC match rate, Haldane flag, GEE corstr used.

    Run for `c("whole", "post")`.

    **Section 3 — suppression helper for tables.**
    ```r
    # Display a 2x2 + totals with complementary suppression:
    # - any cell 1-10 -> "<11"
    # - if a row (or column) has exactly one suppressed interior cell, also suppress that row's
    #   (column's) total so the hidden cell cannot be recovered by subtraction
    # - test statistics are computed on the raw table, never on displayed values
    ```

    **Section 4 — workbook.** openxlsx; sheet order KEY, A_crosstab, B_test, C_sensitivity, QC.
    Header style: fill #0021A5, white bold text; section-title rows in #FA4616. Whole-record and
    post-anchor results side by side (two column blocks per sheet, labelled).
    - KEY: analysis, run date, method (D-165-01) and why (one line from 165-METHODS.md), cutoff,
      distance definition (ZIP-centroid straight line, residence to encounter facility), CBC definition
      (locked R/147) and encounter matching rule (admit to discharge), windows (anchor day = pre),
      encounter scope (all ENC_TYPE), primary = unadjusted with clustering handled by method,
      sensitivity covariates, SOURCE caveat (as worded in 165-METHODS.md), rurality completeness
      (N dropped per window), suppression rule (1-10 shown as "<11", complementary suppression),
      sheet guide.
    - A_crosstab: per window, 2x2 with totals, counts + row %, displayed via Section 3 (percentages
      blanked wherever the underlying count is suppressed).
    - B_test: per window — method, statistic/df (if applicable), p, OR, 95% CI, SE(log OR), DEFF,
      GEE alpha/corstr, N encounters, N patients (N via suppress_display()).
    - C_sensitivity: per window — adjusted far_from_care OR/CI/p, N used, N dropped by reason; then
      the full coefficient table.
    - QC: the Section 2 QC counts per window (suppress_display()).
    - Save to `file.path(CONFIG$output_dir, glue("distance_cbc_association_{format(Sys.Date(), '%Y%m%d')}.xlsx"))`.

    Size `--mem` / `--time` from the prototype timings in 165-01-SUMMARY.md.
