# Plan 138-01: Fix R/13 DuckDB gsub-in-lazy-filter bug

**Phase:** 138 — resolve log2.txt problems

## Goal

`R/13_survivorship_encounters.R` lines 123-128 apply `gsub("\\.", "", DX)` inside a `filter()` on a lazy DuckDB table. DuckDB has no `gsub` function, so dplyr translates this to invalid SQL and throws. Fix by pre-computing combined dotted+undotted IN-lists in R before the filter, matching `R/14_build_cohort.R` lines 140-141 exactly.

---

## Context

**Bug location:** `R/13_survivorship_encounters.R` lines 119-130.

Current code (lines 119-130):
```r
hl_icd10_clean <- gsub("\\.", "", ICD_CODES$hl_icd10)

  # Pre-compute combined dotted+undotted IN-lists before the lazy DuckDB filter.
  # R string functions (gsub, sub) cannot be applied to DuckDB columns inside filter().
  hl_icd10_combined <- unique(c(ICD_CODES$hl_icd10, gsub("\\.", "", ICD_CODES$hl_icd10)))
  hl_icd9_combined  <- unique(c(ICD_CODES$hl_icd9,  gsub("\\.", "", ICD_CODES$hl_icd9)))

  hl_dx_on_encounter <- get_pcornet_table("DIAGNOSIS") %>%
    filter(
      (DX_TYPE == "10" & DX %in% hl_icd10_combined) |
      (DX_TYPE == "09" & DX %in% hl_icd9_combined)
    ) %>%
    distinct(ENCOUNTERID) %>%
    collect()
```

Note: `hl_icd10_clean` and `hl_icd9_clean` are no longer used. Remove those two lines. The combined vectors already include both dotted and undotted forms.
