## Goal

`R/53_death_date_validation.R` line 209 uses `select(ID = PATID, BIRTH_DATE)` to rename `PATID → ID` when querying the DuckDB DEMOGRAPHIC table. This extract renamed the column to `ID` at load time (`R/01_load_pcornet.R` line 91), so `PATID` does not exist in the DuckDB table — the select fails. Fix: change `select(ID = PATID, BIRTH_DATE)` to `select(ID, BIRTH_DATE)`.
