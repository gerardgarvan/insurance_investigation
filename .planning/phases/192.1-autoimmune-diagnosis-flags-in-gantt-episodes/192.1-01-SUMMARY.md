# Phase 192.1 Plan 01: Autoimmune Diagnosis Flags in Gantt Episodes — Summary

**One-liner:** Patient-level autoimmune diagnosis flags (`has_autoimmune_dx` logical, `first_autoimmune_dx_date` Date) added as columns 21–22 to `gantt_episodes.csv` and `gantt_episodes_180.csv`, sourced from DuckDB DIAGNOSIS via GEM-verified ICD-10/ICD-9 prefix matching, with D-08 comparison confirming original columns unchanged.

## ICD-9 Mapping Decisions (D-03, Task 2)

GEM files: `docs/reference/2018_I10gem.txt`, `docs/reference/2018_I9gem.txt` (CMS 2018).

**Accepted ICD-9 codes (14):** 7140, 7141, 7142, 71430, 71431, 71481, 71489, 7149, 4464, 4460\*, 6944\*, 6960, 6961, 6943

**\*Broader codes:**
- `4460` (polyarteritis nodosa): forward GEM maps M31.7 to 4460; reverse maps 4460 to M30.0 (polyarteritis nodosa, outside M31.7). No narrower ICD-9 code exists for microscopic polyangiitis. Included; reported separately in QC.
- `6944` (pemphigus): reverse maps to L10.0, L10.1, L10.2, L10.4, L10.9 (all pemphigus variants, not only L10.0 pemphigus vulgaris). Included; reported separately in QC.

**Excluded ICD-9 codes (4):**
- `3571`: reverse maps to G63 (neurological — outside scope)
- `3596`: reverse maps to G73.7 (myopathy — outside scope)
- `71432`: reverse maps to M08.40 (pauciarticular juvenile RA — outside M083/M0809/M0800)
- `71433`: reverse maps to M08.40 (polyarticular juvenile RA — outside request)

Full table: `.planning/phases/192.1-autoimmune-diagnosis-flags-in-gantt-episodes/192.1-ICD9-MAPPING.md`

## HL Rule Mirror (Task 0 §3)

The HL flag/date pattern in R/52 and R/142 uses a pre-built cohort RDS (`confirmed_hl_cohort.rds`, field `first_hl_dx_date`), with no sentinel comparison step. The autoimmune columns use DuckDB DIAGNOSIS directly with a sentinel gate (D-05a) — this is an expected and recorded difference. The sentinel value (`1910-01-01`) matches the pattern established in R/47/R/48/R/49.

## Scope Decisions

**`gantt_detail.csv` and `gantt_detail_180.csv` excluded from column injection.** These files carry per-event rows (one row per treatment date/code, 14 columns), not per-episode rows. The autoimmune flag is patient-level; it is already present on every episode row including HL and Death pseudo-rows via the episode output. No consumer of the detail files has requested these columns. Recorded as an explicit scope decision; can be added in a future plan if needed.
