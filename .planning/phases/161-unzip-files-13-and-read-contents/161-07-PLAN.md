# 161-07 — Audit all DEATH-reading scripts

**Wave:** 5
**Depends on:** 161-03, 161-04
**Requires team sign-off:** no (but results changes in R/29 are reported to the team)

## Goal

Ensure every script that uses a death date for an endpoint (follow-up end,
time-to-event, survival, person-time, or a plotted end-of-life marker) uses
`resolve_death_date()` and `get_last_activity()`, and document why each remaining
script is exempt. Scripts whose purpose is to study the raw death data keep raw dates.

## Steps

1. Build the list:

   ```bash
   grep -rln -E "DEATH" R/ --include="*.R" | sort
   ```

   Starting list (verify against the grep output; add any new files):
   R/00_config.R, R/01_load_pcornet.R, R/03_duckdb_ingest.R,
   R/29_first_line_and_death_analysis.R, R/35_death_cause_quality.R,
   R/39_run_all_investigations.R, R/51_post_death_encounter_investigation.R,
   R/52_gantt_v2_export.R, R/52_strange_death_source_and_enc_type.R,
   R/53_death_date_validation.R, R/59_death_date_summary.R,
   R/88_smoke_test_comprehensive.R, R/102_death_cause_nhl_flag.R,
   R/103_death_cause_diagnostic.R, R/142_gantt_180_export.R,
   R/147_surveillance_modality_frequency.R, R/161_diag_anchor_followup.R,
   R/filter_strange_death_csvs.R, R/test_phase78_human.R.

2. For each script, read it and assign one category:

   - **Update** — DEATH_DATE feeds an endpoint, person-time, censoring, or a plotted
     death marker. Replace with `death_date_resolved`; take last-contact dates from
     `get_last_activity()`. Patients with NA `death_date_resolved` are not deceased:
     in time-to-event analyses they are censored at `obs_end`.
   - **Exempt: raw-data study** — the script exists to examine recorded death data
     (post-death activity, validation, source quality). Raw dates are required; add
     `# [161-07 audit] Exempt: studies raw DEATH records; resolved dates would hide the cases examined.`
   - **Exempt: no date use** — counts, cause-of-death flags, loading, ingest,
     orchestration. Add `# [161-07 audit] Exempt: does not use DEATH_DATE for an endpoint.`

3. Preliminary categories (confirm by reading each file):

   | Script | Expected category | Note |
   |---|---|---|
   | R/29_first_line_and_death_analysis.R | Update | Time-to-event; results will change (see step 5) |
   | R/51_post_death_encounter_investigation.R | Exempt: raw-data study | Its subject is activity after recorded death |
   | R/53_death_date_validation.R | Exempt: raw-data study | Validates recorded dates |
   | R/52_strange_death_source_and_enc_type.R | Exempt: raw-data study | |
   | R/35_death_cause_quality.R | Exempt: raw-data study | |
   | R/52_gantt_v2_export.R | Update if a death marker is plotted | Flagged patients: no death marker; optionally a distinct "death record not credible" marker |
   | R/142_gantt_180_export.R | Update if a death marker is plotted | Same as above |
   | R/59_death_date_summary.R | Read to decide | Exempt if it summarizes raw records; Update if it reports mortality |
   | R/102_death_cause_nhl_flag.R, R/103_death_cause_diagnostic.R | Exempt: no date use | Cause of death only, unless dates are used |
   | R/00, R/01, R/03, R/39, R/filter_strange_death_csvs.R, R/test_phase78_human.R | Exempt: no date use | |
   | R/88, R/147 | Updated in 161-06 / 161-05 | |
   | R/161_diag_anchor_followup.R | Exempt: raw-data study | Diagnostic |

4. For each Update script: call `get_last_activity()` and `resolve_death_date()`
   (grace 30) for that script's cohort; replace raw DEATH_DATE in `pmin()`,
   `if_else()`, survival objects, and plot data; remove any legacy
   `compute_followup(last_enc =, death =)` call. Run the script and confirm it exits 0.

5. For R/29 (and any other mortality output), produce a short before/after table:
   number of deaths, median follow-up, and the main time-to-event estimate. Write it
   to `output/161_r29_before_after.csv` and summarize for the team in neutral terms
   (e.g. "N deaths changed from X to Y because Z records conflict with later
   clinical activity").

6. Write `output/161_death_audit.csv`:
   `script | category | uses_death_date_in_endpoint | action_taken | resolve_death_date_called | note`.

## Acceptance criteria

- Every script in the grep output appears in the audit CSV with a category.
- No Update-category script uses raw DEATH_DATE for an endpoint, censoring, or plotted marker.
- R/51 and R/53 retain raw dates and carry the exemption comment.
- No production script triggers the `compute_followup()` deprecation warning.
- R/29 before/after table exists and is summarized for the team.
- All updated scripts exit 0 on HiPerGator.
- The R/147 before/after comparison is **not** done here (it is in 161-08).
