# 161-08 — HiPerGator full pipeline re-run + before/after comparison

**Wave:** 5
**Depends on:** 161-01, 161-02, 161-03, 161-04, 161-05, 161-06, 161-07
**Requires team sign-off:** no

## Goal

Run the full pipeline on HiPerGator from ingest through R/147, confirm all smoke tests pass, and record the final `n_implausible` and person-year delta in `161-CONTEXT.md` so the phase is formally closed.

## Steps

1. Start from a clean state: verify that the rebuilt `pcornet.duckdb` from 161-01 is present and current:

   ```bash
   module load R/4.4.2
   Rscript -e '
     source("R/00_config.R")
     con <- DBI::dbConnect(duckdb::duckdb(), CONFIG$cache$duckdb_path, read_only = TRUE)
     cat("DEATH rows:", DBI::dbGetQuery(con, "SELECT COUNT(*) FROM DEATH")[[1]], "\n")
     schema <- DBI::dbGetQuery(con, "DESCRIBE DEATH")
     print(schema[schema$column_name == "DEATH_DATE_IMPUTE", ])
     DBI::dbDisconnect(con)
   '
   ```

   Confirm `DEATH_DATE_IMPUTE` shows VARCHAR. If it still shows DATE, re-run `Rscript R/03_duckdb_ingest.R` first before proceeding.

2. Run the smoke test suite to establish a pre-run baseline:

   ```bash
   Rscript R/88_smoke_test_comprehensive.R 2>&1 | tee output/logs/161_smoke_pre.log
   ```

   Both 161-06 assertions (DEATH_DATE_IMPUTE VARCHAR, follow_end >= hl_anchor_date) must pass. If either fails, stop and diagnose before running the full pipeline.

3. Run the full pipeline in dependency order. Scripts must be run in this sequence (each must exit 0 before starting the next):

   ```bash
   # Core cohort and follow-up
   Rscript R/10_cohort_predicates.R 2>&1 | tee output/logs/161_10.log
   Rscript R/14_build_cohort.R      2>&1 | tee output/logs/161_14.log
   Rscript R/12_surveillance.R      2>&1 | tee output/logs/161_12.log

   # Updated surveillance modality script
   Rscript R/147_surveillance_modality_frequency.R 2>&1 | tee output/logs/161_147.log

   # Scripts updated during 161-07 audit (run each updated script)
   Rscript R/29_first_line_and_death_analysis.R    2>&1 | tee output/logs/161_29.log
   Rscript R/51_post_death_encounter_investigation.R 2>&1 | tee output/logs/161_51.log
   # (Add any other scripts flagged as "update" in 161-07 audit)
   ```

   If any script references a non-existent output from an upstream script, run the upstream script first. Use `R/39_run_all_investigations.R` as a reference for full ordering if needed.

4. Re-run the death sensitivity script to capture final counts:

   ```bash
   Rscript R/161_death_sensitivity.R 2>&1 | tee output/logs/161_sensitivity_final.log
   ```

5. Re-run the diagnostic to confirm the 46 zero-or-negative follow-up patients are resolved:

   ```bash
   Rscript -e 'options(width=200); source("R/161_diag_anchor_followup.R")' 2>&1 | tee output/logs/161_diag_final.log
   ```

   Expected: The 44 "death before anchor" cases now have `death_date_resolved = last_activity_date` and `follow_end >= hl_anchor_date`. The 2 inpatient cases with later discharge dates now have positive follow-up (~8 days each).

6. Run the smoke tests again to confirm end-to-end pass:

   ```bash
   Rscript R/88_smoke_test_comprehensive.R 2>&1 | tee output/logs/161_smoke_post.log
   ```

7. Produce a before/after comparison by diffing key metrics:

   ```bash
   Rscript -e '
     before <- readr::read_csv("output/147_surveillance_modality_frequency_BEFORE_161.csv",
                               show_col_types = FALSE)
     after  <- readr::read_csv("output/147_surveillance_modality_frequency.csv",
                               show_col_types = FALSE)
     comparison <- dplyr::left_join(
       before |> dplyr::select(modality, n_patients_before = n_patients,
                                person_years_before = person_years, rate_before = rate),
       after  |> dplyr::select(modality, n_patients_after  = n_patients,
                                person_years_after  = person_years, rate_after  = rate),
       by = "modality"
     ) |>
     dplyr::mutate(
       py_delta_pct = round((person_years_after - person_years_before) / person_years_before * 100, 2)
     )
     print(comparison, n = Inf)
     readr::write_csv(comparison, "output/161_before_after_comparison.csv")
   '
   ```

   (Save the pre-161 R/147 output as `output/147_surveillance_modality_frequency_BEFORE_161.csv` before starting the pipeline re-run if not already saved.)

8. Record the final numbers in `161-CONTEXT.md` under a new "## Phase 161 final results" section:
   - `n_implausible` at N=30 (from `output/161_death_sensitivity.csv`)
   - Person-years before: 39,107 (from diagnostic)
   - Person-years after: actual value from post-run R/147 output
   - Person-year delta percentage
   - Count of zero-follow-up patients remaining after fix (expected: 0–2)
   - Confirmation that R/88 assertions A and B both pass

9. Commit the updated `161-CONTEXT.md`, all output logs, and the before/after CSV:

   ```bash
   git add 161-CONTEXT.md output/161_before_after_comparison.csv output/logs/161_*.log
   git commit -m "feat(161): full pipeline re-run complete; record final n_implausible and person-year delta"
   ```

## Acceptance criteria

- Full pipeline runs end-to-end without script errors; all log files at `output/logs/161_*.log` show exit 0.
- `R/88_smoke_test_comprehensive.R` passes including both 161-06 assertions (DEATH_DATE_IMPUTE VARCHAR; follow_end >= hl_anchor_date).
- `output/161_before_after_comparison.csv` exists; person-year delta is approximately +0.9% (within ±0.5% of the diagnostic projection of 39,107 to 39,460).
- Zero-follow-up patients (`fu_status == "zero"`) after fix number 0–2 (only the 2 inpatient cases that gain exactly 0 days if admit = discharge = anchor); the 44 death-before-anchor cases all have positive follow-up.
- `161-CONTEXT.md` contains a "Phase 161 final results" section with all required numbers.
- No `n_implausible` regression: count at N=30 is stable relative to 161-03 output (any change is explained by the DEATH_DATE_IMPUTE fix surfacing previously invisible imputed dates).
- `testthat::test_file("tests/testthat/test-161-death-plausibility.R")` reports 0 failures.
