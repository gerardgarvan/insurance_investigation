  <behavior>
    For each patient's zip9_seq spells ordered by period_start_dt, spell i (i greater than 1) is
    a test case: predicted_zip9 = zip9_norm of spell (i-1); actual_zip9 = zip9_norm of spell i;
    gap_days = period_start_dt[i] - period_start_dt[i-1].
    - exact_match: predicted_zip9 == actual_zip9
    - zip5_match: substr(predicted_zip9, 1, 5) == substr(actual_zip9, 1, 5)  (note: zip5_match is
      TRUE whenever exact_match is TRUE -- same-ZIP5 is a superset tier, not mutually exclusive)
    - Patients with only 1 spell (i == 1 for all rows, no prior spell) contribute ZERO test cases
      and must be counted separately as "excluded: no prior spell" -- not silently dropped.
    - gap_days bins: "0-30", "31-90", "91-180", "181-365", "366+" (closed-open on the lower bound,
      i.e. 0-30 means 0 <= gap_days <= 30, 31-90 means 31 <= gap_days <= 90, etc. -- no double
      counting at boundaries).
  </behavior>
  <action>
Append to R/115_zip_stability_counts.R (Section 8, after Task 3 of 139-01).

Build the test-case tibble directly from zip9_seq (do not touch addr_coal or re-load anything):

    validation_cases <- zip9_seq %>%
      arrange(ID, period_start_dt) %>%
      group_by(ID) %>%
      mutate(
        predicted_zip9 = lag(zip9_norm),
        predicted_start = lag(period_start_dt),
        gap_days = as.numeric(period_start_dt - predicted_start)
      ) %>%
      ungroup() %>%
      filter(!is.na(predicted_zip9))   # drops each patient's first spell -- no prior to predict from

    n_excluded_no_prior <- n_distinct(zip9_seq$ID) - n_distinct(validation_cases$ID)
    message(glue("A-06: {n_excluded_no_prior} patients excluded from hold-out test (only 1 ZIP9 spell, no prior to predict from)"))
    message(glue("A-06: {nrow(validation_cases)} hold-out test cases across {n_distinct(validation_cases$ID)} patients"))

    validation_cases <- validation_cases %>%
      mutate(
        exact_match = predicted_zip9 == zip9_norm,
        zip5_match  = substr(predicted_zip9, 1, 5) == substr(zip9_norm, 1, 5),
        gap_bin = case_when(
          gap_days <= 30  ~ "0-30",
          gap_days <= 90  ~ "31-90",
          gap_days <= 180 ~ "91-180",
          gap_days <= 365 ~ "181-365",
          TRUE            ~ "366+"
        )
      )
