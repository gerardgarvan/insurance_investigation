<objective>
Fix the `$ operator is invalid for atomic vectors` crash in R/109 Section 6.

Root cause: `before` and `after` are both source data frame names and column names
inside the same `tibble()` call. When R evaluates `after = c(n_distinct(after$ID), ...)`,
the name `after` resolves to the numeric column just created, not the data frame.

Purpose: Allow R/109 to run end-to-end on HiPerGator without crashing at the headline summary.
Output: Patched R/109 with renamed intermediate frames and pre-computed scalars.
</objective>
