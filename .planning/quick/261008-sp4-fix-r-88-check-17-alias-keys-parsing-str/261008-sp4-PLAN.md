# Quick Task 261008-sp4: Fix R/88 Check 17 alias_keys Parsing

## Root Cause

R/88 Check 17 parses the DRUG_NAME_ALIASES block from R/00_config.R source text.
At line 1860 it extracts alias keys by splitting on `=` and trimming whitespace,
yielding strings like `"adriamycin"` (with surrounding R double-quote characters).

`required_dox_keys` contains bare strings (`adriamycin`, `doxil`, …).
`setdiff(required_dox_keys, tolower(alias_keys))` never finds a match because the
quotes are still present, so Check 17 always FAILs even though all keys exist.

## Fix

**File:** `R/88_smoke_test_comprehensive.R` line 1860

Change:
```r
alias_keys <- trimws(ifelse(grepl("=", alias_code), sub("=.*$", "", alias_code), ""))
```

To:
```r
alias_keys <- gsub('"', '', trimws(ifelse(grepl("=", alias_code), sub("=.*$", "", alias_code), "")))
```

The `gsub('"', '', ...)` strips all double-quote characters from parsed key tokens,
leaving bare lowercase strings that match `required_dox_keys`.
