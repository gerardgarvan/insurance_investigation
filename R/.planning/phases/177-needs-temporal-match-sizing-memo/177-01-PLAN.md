**SECTION 6 — D-01 Decision row: ZIP5-missing encounters coverable by a dated address record:**
Scoped to enc_distance (the Phase 165 analytic universe). An encounter is "coverable"
when get_zip9_at_date returns match_type == "interval" for that (ID, ADMIT_DATE) pair.

```r
# Candidate encounters: patient_zip_missing AND patient is in NEEDS_TEMPORAL_MATCH
enc_candidates <- enc_distance |>
  dplyr::filter(distance_status == "patient_zip_missing",
                ID %in% ntm_ids)
n_candidates <- nrow(enc_candidates)
message(glue("  Decision row candidates (patient_zip_missing, NEEDS_TEMPORAL_MATCH): {n_candidates}"))

# Temporal lookup — does a dated address record cover each encounter date?
lookup_result <- get_zip9_at_date(
  ids   = enc_candidates$ID,
  dates = enc_candidates$ADMIT_DATE
)
# Mark coverable = match_type == "interval" (covering record exists for that date)
enc_candidates <- enc_candidates |>
  dplyr::left_join(
    lookup_result |> dplyr::select(ID, query_date, match_type),
    by = c("ID" = "ID", "ADMIT_DATE" = "query_date")
  ) |>
  dplyr::mutate(coverable = !is.na(match_type) & match_type == "interval")

n_coverable_whole   <- sum(enc_candidates$coverable, na.rm = TRUE)
n_coverable_pat     <- dplyr::n_distinct(enc_candidates$ID[enc_candidates$coverable])
```
